# WinUI Netflix

A lightweight Netflix desktop application built with WinUI 3 and WebView2.

## Features

- Netflix Web experience in a native WinUI 3 window
- Custom Netflix navigation bar
- Search
- Profile menu
- Language settings
- Startup launch
- Animation toggle
- Netflix reload
- Windows 10 support

## Requirements

- Windows 10/11
- x64
- WebView2 Runtime

## Installation

Download the latest MSIX Bundle from Releases.
